نسخه قفل‌شده طراحی دکودور اسدی
این نسخه ظاهر صفحه را دقیقاً مطابق تصویر تأییدشده نمایش می‌دهد و تصویر کامل داخل خود سایت قرار گرفته است تا هیچ عکس یا استایلی هنگام باز کردن فایل محلی خراب نشود.
لینک‌های واتساپ و اینستاگرام و چند ناحیه سفارش روی نسخه دسکتاپ فعال هستند.
برای مرحله بعدی، می‌توان همین ظاهر را به سایت کاملاً واقعی و تعاملی با سبد خرید، مدیریت محصولات، قیمت‌ها و پرداخت آنلاین تبدیل کرد.
